# @pokecrystal/web

ASM-faithful Next.js and React app for the PokeCrystal runtime.

## Status
- This workspace is private and is not intended for npm publication.
- It is the primary browser-facing consumer of `@pokecrystal/core`, `@pokecrystal/assets`, and `@pokecrystal/exporters`.
- The build is designed to work locally and in Vercel-style deployments.

## Prerequisites
- Node.js `24.x`
- npm `>=10.5.0`
- Root workspace dependencies installed from the repository root
- A local `vendor/pokecrystal/` checkout for asset preparation and exporter-backed flows
- Optional `.env.local` for Next.js runtime configuration

## Commands
- `npm run dev`: start the app with Next.js' default development dist directory.
- `npm run build`: prepare public assets, clean prior Next artifacts, and build into `.next-build` by default.
- `npm run start`: start the production Next server.
- `npm run lint`: run `lint:types` and `lint:eslint`.
- `npm run lint:types`: run the workspace-aware TypeScript check.
- `npm run lint:eslint`: run ESLint for this workspace.
- `npm run test`: run the Jest suite.
- `npm run audio:bundle`: legacy/export utility for regenerating the ignored browser MP3/manifests bundle. Runtime playback uses direct PCM synthesis from `vendor/pokecrystal/audio` or `POKECRYSTAL_DISASSEMBLY_ROOT` and does not require this bundle.
- `../../export`: run the canonical core pack export through the Rust `crystal-assets` crate.
- `npm run pw:install`: install Chromium for the Playwright harness.
- `npm run pw:pages`: run route smoke coverage and visual baseline comparisons.
- `npm run pw:pages:mobile`: run route and visual checks against mobile device profiles.
- `npm run pw:visual:update`: refresh Playwright visual baselines after intentional UI changes.
- `npm run pw:ci`: run the stricter Playwright CI profile.
- `npm run vercel-build`: Vercel build hook alias.

## Workspace Notes
- Install dependencies from the repository root, not from `apps/web`.
- The `@/` alias is defined in `tsconfig.json`.
- Shared runtime logic should stay in `@pokecrystal/core`, `@pokecrystal/assets`, or `@pokecrystal/exporters` instead of being duplicated in the app.
- Playwright artifacts land in `output/playwright/<timestamp>/`; visual baselines live in `tests/baselines/chromium/`.

## Public Disassembly Mirror
- `apps/web/public/disassembly` is generated by `scripts/prepare-public.js`.
- Local development links that directory back to the `vendor/pokecrystal/` checkout.
- Production-style builds copy the required files into the public tree when needed.

## Debugging Script Runner Stalls
- The in-app Event Log panel uses `pushDebugLog(...)` as a ring buffer.
- To mirror those entries to the browser console, enable `poke_debug_console`.
- Query-string example: `?poke_debug=script,script:cmd,script:stack&poke_debug_console=1`
- DevTools example:

```js
localStorage.setItem("poke_debug", "script,script:cmd,script:stack");
localStorage.setItem("poke_debug_console", "1");
location.reload();
```

- `.env.local` example:

```bash
NEXT_PUBLIC_POKE_DEBUG=script,script:cmd,script:stack
NEXT_PUBLIC_POKE_DEBUG_CONSOLE=1
```

- Add `script:strict` to `poke_debug` to throw on unknown script commands.

## Game Loop Profiling
- Add `flare_plot` to `poke_debug` to draw the in-engine flare plot and begin frame benchmarking for `handleInput`, `update`, and `draw`.
- Query-string example: `http://localhost:3000/?poke_debug=flare_plot`
- DevTools example:

```js
localStorage.setItem("poke_debug", "flare_plot");
location.reload();
```

- Inspect recent frame timings in DevTools with `window.get_game_benchmark()`.
- Pass a threshold such as `window.get_game_benchmark(16.67)` to inspect slow frames above one Game Boy frame budget.
- Use `window.clear_game_benchmark()` before starting a fresh capture.
- Profiling helpers are wired directly in the runtime and can be explored from the browser DevTools console.
